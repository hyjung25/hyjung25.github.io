# Personal Portfolio Website

A responsive portfolio website for Project 1. It includes an About Me section, project placeholders, contact links, a contact form, and JavaScript interactions for dark mode and the mobile navigation menu.

## Customize

1. Replace `assets/profile-placeholder.png` with a real photo.
2. Confirm the GitHub and LinkedIn links in `index.html`.
3. Add live project links as the semester projects become available.
4. Publish with GitHub Pages from the repository settings.

## Run Locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
