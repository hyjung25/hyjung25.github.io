# Submission Checklist

## Done in this folder

- Static `index.html` game with plain HTML/CSS/JavaScript.
- Local Three.js copy in `vendor/three`.
- No build step.
- Crossy Road-style movement, hazards and score.
- Updated README structure for the assignment.
- `prompt_log.md` with the important prompts from this finishing session.

## Before submitting

- Replace the TODO in `README.md` with your own 1-2 sentence game description.
- Add any earlier in-class prompts to `prompt_log.md` if they are missing.
- Commit and push the portfolio repo so the game is live on GitHub Pages.
- Submit the live portfolio/game links in the course form.

`REFLECTION.md` is only needed if you hit the 4-hour cap without finishing.
